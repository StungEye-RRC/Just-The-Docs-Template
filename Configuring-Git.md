#Configuring Github Remote

How does one add a github remote?
in order to tell your local repository where the remote repository is you must:

-Go to github
-create the remote repository if you haven't already
-copy the URL
-and add it to your local through a command "git remote add"

in order to check if it worked, a good way to check is "git remote -v" From that command you should see your Github URL listed
