# Pushing
When you push, you send your local code to github for your repository "git push -u" Whatever your repository's name is "main"
-u remembers the connection so pushing is much easier next time, after that you can just use "git push"

# Pulling
pulling gets changes from github to your computer using "git pull", it downloads them from your repository to your git on your PC and merges them
